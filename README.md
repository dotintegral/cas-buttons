# CAS Buttons
Open-source Button models for Haute42 C-AS arcade stick

## Files
- `*.stl` - great to 3d print (either on your own or send it to a 3d printing service)
- `*.step` - if you want to modify them

## Source

Original source is available in [Onshape project](https://cad.onshape.com/documents/506daf69a9f3e20d372be9dd/w/a3f34844fce94ab9c0890280/e/bca400526695701ace7d2d06)
